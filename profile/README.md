## 关于鼠群

四非保研鼠群由来自**四非院校**、就读**计算机相关专业**的同学组成。保研过程中信息不对称的问题普遍存在，四非院校的同学尤其明显。鼠群整理招生信息、实用资源和亲身经历，供同学们互相参考。

鼠群现有 1000 多位成员，覆盖各个年级，其中不少已经完成保研。**入群和日常交流均免费**，鼠群不提供任何付费辅导。
