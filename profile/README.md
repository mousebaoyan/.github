## 🐭 关于鼠群

我们是一群来自**四非院校**、学**计算机相关专业**的同学。保研路上信息不对称，四非同学尤其吃亏，所以我们把招生信息、实用资源和亲身经历整理出来，互相帮一把。

鼠群里有 1000 多位群友，各个年级都有，也有不少已经上岸的学长学姐。**入群和日常交流都免费**，鼠群不提供付费辅导。
